# Claw Consultoria — site institucional

Site estático em HTML, CSS e JavaScript, pronto para GitHub + Netlify.

## Publicação no Netlify

- Suba estes arquivos para um repositório no GitHub.
- No Netlify, use **Add new project → Import an existing project → GitHub**.
- Para este projeto, deixe **Build command** vazio e **Publish directory** como `.` ou `/` conforme a interface apresentar.

## Observação

Os textos institucionais são genéricos e podem ser ajustados para refletir exatamente os serviços, contatos e informações comerciais reais da empresa.
